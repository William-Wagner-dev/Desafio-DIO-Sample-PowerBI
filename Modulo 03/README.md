# 📊 Relatório Gerencial de Vendas — Desafio DIO (Formação Power BI Analyst)

Projeto desenvolvido como parte do **Desafio de Projeto da DIO**, dentro da trilha de **Formação Power BI Analyst**. A partir de uma Sample do Power BI Desktop, foi construída uma dashboard completa e funcional, com layout personalizado, navegação entre páginas, indicadores, segmentadores e botões interativos para alternância entre visuais.

## 🚀 Sobre o projeto

O relatório foi criado seguindo as premissas propostas no desafio, com foco não apenas nos dados, mas também na experiência de navegação do usuário dentro do dashboard — utilizando botões, ícones e segmentadores para tornar a análise mais interativa e intuitiva.

## 📄 Estrutura do relatório

O relatório é composto por duas páginas principais, conectadas por botões de navegação:

**Página 1 — Sales Report**
* Cabeçalho com identidade visual da Formação Power BI Analyst (DIO)
* Segmentador de data (Selecione a Data), com botão de limpar filtro
* Cartões indicadores: Total de Vendas, Unidades Vendidas, Soma de Descontos, Soma de Sale Price, Soma de COGS
* Gráfico de área: Soma de Sales por Mês
* Visual "Vendas x Segmento", com botões para alternar entre **Bar Chart** e **Pie Chart**
* Gráfico de barras: Soma de Vendas por Produto
* Visual "Vendas x País", com botões para alternar entre **Treemap** e **Map Chart**
* Botão de navegação (seta) para a página seguinte

**Página 2 — Report de Lucro Detalhado**
* Botão de navegação (seta) para retornar à página anterior
* Visual de hierarquia/decomposição: Soma de Profit por Ano e Country
* Segmentadores: Ano e Country
* Gráfico radar: Soma de Profit por Product
* Gráfico de árvore (Treemap): Soma de Profit por Segment
* Gráfico em cascata (waterfall): Soma de Profit por Trimestre

## 🔧 Etapas realizadas no desafio
